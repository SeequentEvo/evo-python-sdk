evo.compute.discovery.DiscoveryClient

List the compute task catalogue for an organization.

Returned tasks are independent copies, so editing them does not affect the cache.

Parameters:

Name Type Description Default
connector APIConnector

The API connector to use.

 required
org_id UUID

The organization ID.

 required
cache_ttl_seconds float

How long a fetched catalogue is cached before the next call re-fetches it. Pass force_refresh=True to any accessor to re-fetch sooner.

 DEFAULT_CACHE_TTL_SECONDS
