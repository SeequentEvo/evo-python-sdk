from_url async staticmethod 

from_url(context: IContext, url: str, *, preview: bool = False, fb: IFeedback = NoFeedback) -> TaskJob[Any]

Reopen a saved status URL with discovery hydration and native result conversion.

The URL must belong to the context's hub and organization. Preview is not encoded in the URL, so preview jobs require preview=True again. Discovery determines the result type; a URL alone cannot describe it statically.

map 

map(convert: Callable[[TResult], Awaitable[TMapped]]) -> TaskJob[TMapped]

Convert results asynchronously while preserving the same job and wait options.

Conversion runs only when results is awaited. Conversion errors propagate to the caller, just like errors from the platform.
