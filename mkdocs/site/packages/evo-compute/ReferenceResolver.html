evo.compute.resolution.ReferenceResolver

Resolves a task's caller-supplied parameters into the payload the platform expects.

One instance serves every task. Object schemas are cached for the lifetime of the resolver, so an object referenced by several parameters is only fetched once.

Parameters:

Name Type Description Default
context IContext

An authenticated Evo context, used to load referenced objects.
