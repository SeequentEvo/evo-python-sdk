evo.compute.engine.ComputeClient

Instance-bound async entry point to the compute task catalogue.

Reach a task as client.<topic>.<task> and call await client.<topic>.<task>.run(...) to submit it and wait for its results. arun does the same for names held as strings.

Parameters:

Name Type Description Default
context IContext

An authenticated Evo context.

 required
cache_ttl_seconds float

How long a discovered task catalogue is cached.

 DEFAULT_CACHE_TTL_SECONDS
validate bool

Validate parameters against the task schema before submitting (required-field presence). Defaults to True. This is the master switch: False turns off deep validation too, whatever deep_validation says.

 True
deep_validation bool

Additionally run full JSON Schema Draft 2020-12 validation. Defaults to False. Only consulted when validate is True.

 False

arun async 

arun(
    topic: str,
    task: str,
    parameters: dict[str, Any],
    *,
    validate: bool | None = None,
    deep_validation: bool | None = None,
) -> dict

Run a task by name and wait for its results.

The same as await client.<topic>.<task>.run(**parameters), for names held as strings. Names may be spelled as the platform publishes them or with underscores.

Parameters:

Name Type Description Default
topic str

The task topic.

 required
task str

The task name.

 required
parameters dict[str, Any]

The task parameters, plus preview=True to run a preview task.

 required
validate bool | None

Override the client's shallow-validation setting for this call. The master switch: False skips deep validation too.

 None
deep_validation bool | None

Override the client's deep-validation setting for this call. Only consulted when validation is enabled.

 None
