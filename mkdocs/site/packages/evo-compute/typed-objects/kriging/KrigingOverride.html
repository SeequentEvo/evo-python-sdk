evo.compute.overrides.geostatistics.kriging.KrigingOverride

The override's stand-in for the generic task proxy: same run(...), typed by hand.

run 

run(
    *,
    source: _SourceInput,
    target: _TargetInput,
    variogram: _ObjectInput,
    neighborhood: SearchNeighborhood,
    kriging_method: SimpleKriging | OrdinaryKriging | None = None,
    source_filter: Filter | None = None,
    target_filter: Filter | None = None,
    block_discretization: BlockDiscretization | None = None,
    diagnostics: KrigingDiagnostics | None = None,
    preview: bool = False,
) -> KrigingResult

Estimate an attribute on a target object by kriging from a source attribute.

Parameters:

Name Type Description Default
source _SourceInput

The object and attribute holding the known values, or the typed attribute itself.

 required
target _TargetInput

Where to write the estimate -- a Target, or the typed attribute to create or update.

 required
variogram _ObjectInput

The variogram object, or a reference to it.

 required
neighborhood SearchNeighborhood

The search neighbourhood: the ellipsoid to look in, and how many samples to use.

 required
kriging_method SimpleKriging | OrdinaryKriging | None

Ordinary kriging by default; KrigingMethod.simple when the mean is known.

 None
source_filter Filter | None

Restrict the estimate to a subset of the source data.

 None
target_filter Filter | None

Restrict the estimate to a subset of the target object.

 None
block_discretization BlockDiscretization | None

Sub-block discretization for block kriging. Omitted means point kriging.

 None
diagnostics KrigingDiagnostics | None

Optional diagnostic attributes to write beside the estimate.

 None
preview bool

Opt in to the preview API. Defaults to False.

 False

Raises:

Type Description
ParameterValidationError

If the parameters are inconsistent in a way the task schema cannot describe, or fail the engine's own checks.
