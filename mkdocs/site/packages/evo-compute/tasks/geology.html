classify_by_domain

client.geology.classify_by_domain · Task: geology/classify-by-domain · Version: 0.1.0 · Preview (preview=True required)

Classifies locations from a source geometry object against an ordered list of domain entries (volumes and surfaces), writing a categorical attribute back to the source object.

await client.geology.classify_by_domain.run(
    *,
    source: GeologyClassifyByDomainSource,
    domain_entries: list[GeologyClassifyByDomainVolumeEntry | GeologyClassifyByDomainSurfaceEntry],
    output: GeologyClassifyByDomainOutput,
    preview: bool = False,
) -> GeologyClassifyByDomainResult

await client.geology.classify_by_domain.submit(
    *,
    source: GeologyClassifyByDomainSource,
    domain_entries: list[GeologyClassifyByDomainVolumeEntry | GeologyClassifyByDomainSurfaceEntry],
    output: GeologyClassifyByDomainOutput,
    preview: bool = False,
) -> TaskJob[GeologyClassifyByDomainResult]

Parameters:

Name Type Description Default
source GeologyClassifyByDomainSource Source geometry object whose locations will be classified. required
domain_entries list[GeologyClassifyByDomainVolumeEntry | GeologyClassifyByDomainSurfaceEntry] Ordered list of domain entries defining the classification hierarchy. Locations are evaluated against entries in order; the first matching entry wins. Each entry is either a VolumeEntry (inside/outside a closed mesh) or a SurfaceEntry (above/below an open mesh surface). required
output GeologyClassifyByDomainOutput Output attribute configuration. required
preview bool Opt in to preview execution (required for this preview task: pass preview=True). False
