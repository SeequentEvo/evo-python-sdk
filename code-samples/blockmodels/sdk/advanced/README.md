# Advanced Block Model SDK Tutorials

This directory is reserved for SDK workflows that require specialized grid definitions or larger data-management patterns. These topics should remain separate from the regular block model learning path.

Planned topics:

- Subblocked, fully subblocked, flexible, and octree grid definitions
- Subblocked-column updates and `fill_subblocks`
- Large-query export and cache-backed workflows
- Version-delta and synchronization workflows

Start with the [main Block Model SDK tutorials](../README.md) before working through these examples.
