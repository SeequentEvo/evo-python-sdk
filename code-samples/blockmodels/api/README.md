# Block Model Direct API Reference

This directory contains advanced examples that call the Block Model service directly. These notebooks are not the recommended starting point for application development.

Begin with the [SDK tutorials](../README.md) for high-level operations, PyArrow integration, validation, and reduced request-management code.

Use [Block Model API Reference Workflows](block-model-api-reference-workflows.ipynb) when you need to inspect raw requests and responses, debug an integration, or use a service capability that the SDK does not yet expose.
The request and response patterns in these examples can also be adapted for applications written in languages other than Python.

Generated query results are written to `downloads/` and are excluded from version control.
